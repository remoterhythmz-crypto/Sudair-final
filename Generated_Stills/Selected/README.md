# Sudair three-month generated stills and stories

54 image concepts correspond one-to-one to the 54 IDs in `Sudair_3Month_Still_Post_Prompts.md`: 18 feed stills and 36 stories. This folder is the selected image set; earlier rejected experiments remain outside it. All images were generated with the built-in image tool from the supplied prompts and Sudair source references.

These are **internal creative concepts, not cleared publication masters**. The source prompt explicitly reserves the logo area for the official file. Place the supplied logo from `../brand_assets/logos/` as a separate layout element; do not rely on any rendered logo in an image. Proofread Arabic letter joining and every English line at full size. Confirm rights and written consent for depicted people. Validate any reconstructed view of a Sudair site against the real source photograph; AI composites may invent detail. January pieces listed in `../Sudair_3Month_Claims_and_Approval_Review.md` remain held for client quality/regulatory review. `Image_QA_Manifest.csv` records the source paths and checks per image.

Canvas output varies by image model; crop and export to the specified 1080×1350 feed or 1080×1920 story size only after visual review. No images have been placed into the presentation.
